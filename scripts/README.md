# Scripts

- `setup/`: local and cluster bootstrap, Apptainer entrypoints, and environment validation.
- `data/`: BraTS download, validation, preprocessing, indexing, and partition helpers.
- `federated/sam/`: SAM1/SAM2 federated training, evaluation, and comparison helpers.
- `federated/placeholders/`: direct server/client placeholder launchers.
- `cluster/`: cluster log syncing and queue-watching utilities.
